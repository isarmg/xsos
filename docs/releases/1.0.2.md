# xsos 1.0.2

- 显卡页面不再按型号、显存容量或活动状态猜测合并不同 DXGI LUID 设备与无 LUID ADLX 读数。每条采集记录独立展示，保留采集端已经证明的关联。
- 无 LUID 的 ADLX 温度、功耗和频率可能单独显示。这不代表新增物理显卡，也不能据此把这些读数分配给同型号的某张卡。
- 公共支撑固定为已发布 xcss 1.0.5，Rust revision 为 `6a8113d4be76e5e8977ac7be08c1a7c57963ae49`；Web 包固定发行 URL 与完整性摘要。
- 产品版本更新至 1.0.2；协议包、Schema 应用版本与 API 版本保持独立，未改变采集端或线协议。

## 验证边界

新增 GPU 身份回归覆盖同型号多卡、仅一张卡活跃、零活动值、无 LUID 传感器及采集端已关联记录。受控数据的单元或渲染测试不能代替真实 Windows 多 GPU 硬件验证。原生浏览器与真实硬件尚未验证。
