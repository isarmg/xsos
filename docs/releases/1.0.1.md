# xsos 1.0.1

## 自 1.0.0 以来的更新

- 刷新监控报表时保留用户选择的日期，不再跳回默认日期。
- 请求失败时保留已有监控视图，便于恢复后继续查看。
- 历史温度图保留带符号的摄氏值，正确显示零下温度。
- Rust 与内嵌管理 Web 同步采用已验证并锁定的 xcss 1.0.2。
- 更新部署、监控工作流与故障排查文档，安装路径同步为 1.0.1。
- 协议包显式固定为 1.0.0，软件发行号独立升级；数据库格式和配置身份保持不变。

## 下载与安装

平台：Linux x86_64 GNU。发行资产：`xsos-1.0.1-x86_64-unknown-linux-gnu.tar.gz` 和 `xsos-1.0.1-x86_64-unknown-linux-gnu.tar.gz.sha256`。

安装步骤见[部署指南](../server-release-readme.md)。
